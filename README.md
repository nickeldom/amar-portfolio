## Running Locally

Clone the repository:

```bash
git clone https://github.com/nickeldom/amar-portfolio.git
````

Enter the project:

```bash
cd amar-portfolio
```

Run a local server:

```bash
python3 -m http.server 8000
```

Open:

```
http://localhost:8000
```
